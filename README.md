# steiger-vscode

This is a language server extension for [steiger](https://github.com/feature-sliced/steiger).

> [!WARNING]  
> This extension requires language server shipped with `steiger@0.7.0` or newer


## Development

Run `pnpm dev` to start vscode with the extension loaded.

In order to pack `vsix` file, run `pnpm build` and then `pnpm package`.
